Unmodified `fa-solid-900.ttf` from Font Awesome Free **6.7.2** (Fonticons, Inc.).

- Upstream: https://github.com/FortAwesome/Font-Awesome/tree/6.7.2
- File: https://github.com/FortAwesome/Font-Awesome/blob/6.7.2/webfonts/fa-solid-900.ttf

- Font license: SIL Open Font License 1.1. The upstream license and copyright notices are preserved in [LICENSE.txt](LICENSE.txt), also embedded in the app's Help → Third-party notices window.

The font is embedded at compile time and used through a dedicated icon font family. No network request or system installation is needed. Glyph mappings are based on the pinned upstream `metadata/icons.json`; tooltips and accessibility labels describe the actions independently of the glyphs. Use this icon family for additional standard toolbar actions rather than drawing ad hoc replacement icons.
