The regular face is embedded once and prioritized for both proportional and monospace text families, including Korean names, numbers, rulers, menus and dialogs. Existing fallback fonts handle missing symbols. Font Awesome remains a separate icon family. No system font installation, runtime font-file read, network request or new runtime dependency is required. Native operating-system file dialogs retain the OS font.
