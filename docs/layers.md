# 레이어 완성 계획

2026년 10월 20일 시작

현재 우선 작업은 상단 레이어 메뉴다.
시작할 때 미구현 항목은 54개였다. 3D 관련 2개는 나중으로 미룬다.
아래 52개를 실제로 쓸 수 있게 만드는 것이 이번 목표다.
체크가 없으면 아직 완료가 아니다. 날짜만으로 완료를 약속하지 않는다.

## 완료 기준

- 메뉴와 화면에서 실제로 동작한다.
- 잠금과 여러 레이어 선택 규칙이 맞는다.
- 확정과 취소, 실행 취소와 다시 실행이 맞는다.
- 저장하고 다시 열어도 결과가 남는다.
- 큰 그림의 메모리와 저장 한도를 지킨다.
- 자동 검사와 별도 데이터로 실제 화면을 확인한다.

새 레이어 종류는 이름만 다른 픽셀 레이어로 대신하지 않는다.
벡터는 선을 다시 편집할 수 있어야 한다. 색 보정 레이어는 원본을 바꾸지 않아야 한다.
작동하지 않는 버튼의 미구현 표시만 지우지 않는다.

참조 표시는 자동 선택과 참조 레이어 채우기의 입력으로 사용한다. 벡터 중심선에서 정지하거나 경계 넘침을 방지하는 기능은 포함하지 않는다.
밑그림은 캔버스와 작업 파일에 남기고 기본 PNG 출력에서 뺀다.
별도 기본 설정 창은 활성 레이어의 이름과 불투명도, 합성과 기본 설정을 한 번에 바꾼다.
폴더의 투명 픽셀 잠금처럼 맞지 않는 설정은 비활성화한다.
이 창은 색 보정이나 채우기 내용을 다시 편집하는 상세 설정과 다르다.
이전 집계에서 둘을 섞어 센 부분을 바로잡았다. 선택과 마스크를 포함해 대상 중 11개를 반영했고 41개가 남았다.
다음은 새 레이어 종류와 종류별 상세 설정이다. 마스크 연결은 이동과 변형을 만들 때 함께 진행한다.

## 2 폴더

- [x] 새 레이어 폴더
- [x] 폴더를 만들어 레이어 넣기
- [x] 레이어 폴더 해제

넣기와 꺼내기, 접기와 드래그 순서 변경을 함께 확인한다.
폴더의 표시와 불투명도, 합성과 마스크가 하위 레이어에 적용되어야 한다.

중첩 자료와 고립 합성에 생성 메뉴와 접기, 하위 트리 이동과 복제, 삭제를 연결했다.
폴더 안팎 드래그와 마스크 그리기를 지원한다. 통과 합성은 하위 레이어의 합성을 바깥 배경에 적용한다.
불투명도와 마스크는 폴더 전체 결과에 한 번 적용한다.
통과 폴더를 클리핑하면 통과 효과가 멈추며 빨간 글씨로 안내한다. 클리핑을 풀면 다시 적용한다.
다른 레이어를 통과 폴더에 클리핑하는 것은 막는다.
실제 창에서 모드 전환과 설정 취소, 마스크 그리기와 실행 취소, 해제와 재열기를 확인했다.
접힘 상태는 실행 중에만 유지한다. 폴더 해제는 자식을 남기고 폴더 자체 효과를 없앤다.
새 폴더의 기본 합성은 표준이다. 폴더 마스크 적용과 계층 레이어 합치기는 아직 지원하지 않는다.

## 3 선택과 마스크

- [x] 레이어에서 선택 범위 만들기

- [x] 선택 범위에서 빼기

- [ ] 마스크와 레이어 연결

부분 투명한 경계와 빈 범위를 구분한다.
마스크 연결은 실제 이동과 변형까지 함께 동작해야 한다.

선택 메뉴와 단축키 설정에 실제 연산을 연결했다. 전체 선택과 해제, 반전도 쓸 수 있다.
여러 레이어와 폴더의 그림에서 반투명 선택을 만들고 선택 안에서만 그린다.
원본의 표시 불투명도와 합성 모드는 선택 모양에 넣지 않는다. 폴더에서는 보이는 자식의 그림과 마스크를 모은다.
구멍이 있는 경계도 패닝과 확대를 따라간다. 아주 복잡한 모양은 경계 표시만 줄이고 이를 안내한다.
선택 결과가 전부 비면 선택을 해제하고 알린다. 선택 없이 마스크를 만들면 전체를 보인다.
실행 취소와 다시 실행, 저장 후 재열기를 확인했다. 자유 선택 도구와 선택 런처는 아직 없다.

## 4 새 레이어 종류

- [ ] 벡터 레이어
- [ ] 그라데이션
- [ ] 채우기
- [ ] 톤
- [ ] 컷 테두리 폴더
- [ ] 용지

설정값과 원래 자료를 저장하고 나중에 다시 고칠 수 있어야 한다.
용지는 일반적인 잠긴 흰색 레이어와 구분한다.

채우기와 용지는 색 설정을 저장하는 별도 종류로 합성 기반을 만들었다.
색 전체를 픽셀 배열로 복사하지 않고 필요한 줄만 계산한다. 채우기는 선택 범위를 마스크로 보존한다.
용지는 하나만 둘 수 있고 맨 아래에 고정한다. 기존 파일의 흰 픽셀 배경은 자동으로 바꾸지 않는다.
생성 메뉴와 색 재편집 창을 연결하기 전이라 두 항목은 아직 미완료다.

## 이미 있는 기반

픽셀 레이어 생성과 복제, 삭제와 순서 변경, 표시와 잠금, 투명 잠금과 클리핑은 있다.
이름 변경, 마스크 편집, 일부 결합과 작업 기록도 있다.
새 종류와 폴더를 더할 때 기존 동작이 계속 맞는지도 검사한다.

3D 레이어와 3D 인체 모델은 이번 목록에 포함하지 않는다.
전체 제품 순서는 [개발 로드맵](roadmap.md), 현재 작동 범위는 [구현 현황](status.md)을 본다.
